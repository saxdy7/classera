# 🎓 Community Rules (WhatsApp-Style for Education)

## Overview
Communities in this platform work **like WhatsApp Communities** but with **stricter, university-grade, mentor-controlled rules** for professional education.

---

## 1️⃣ Community Creation Rules

### ✅ Who Can Create
- **Only mentors** can create communities
- **Students cannot** create communities

### 📋 Requirements
- Must be **university-specific** (auto-assigned)
- Must have clear **purpose/goal**
- Optional: Specialization-specific (Full Stack, AI/ML, etc.)

### 📝 Naming Convention
Format: `[University] – [Purpose]`

Examples:
- ✅ `LPU – Frontend Interview Prep`
- ✅ `Parul – Cloud Computing Study Group`
- ✅ `SRM – AI/ML Project Team`
- ❌ `Random Group` (too vague)

### 🔢 Limits
- Mentor can create **unlimited communities**
- Each community can have **unlimited members** (configurable)

---

## 2️⃣ Community Visibility Rules

### 🏫 University Isolation
- Students see **only their university's communities**
- Mentors see **only their university's communities**
- **Cross-university communities**: ❌ Not allowed

### 👀 Who Can See
| User Type | Can See |
|-----------|---------|
| Student (LPU) | ✅ All LPU communities |
| Student (Parul) | ✅ All Parul communities |
| Mentor (LPU) | ✅ All LPU communities |
| LPU Student | ❌ Parul communities |

---

## 3️⃣ Joining & Approval Rules

### 🚫 No Auto-Join
- Students **cannot auto-join**
- Must send **join request**

### 📝 Join Request Flow
1. Student clicks "Join Community"
2. Status: **Pending** ⏳
3. Mentor receives notification
4. Mentor can:
   - ✅ **Approve** → Student joins
   - ❌ **Reject** → Request denied
   - ⏳ **Keep Pending** → No action yet

### 👨‍🏫 Mentor Powers
- Can **directly add students** (skip approval)
- Can **remove any student** at any time
- Can **view join request history**

### 🔄 Re-joining
- Removed students **cannot auto-rejoin**
- Must send **fresh join request**
- Mentor must **re-approve**

---

## 4️⃣ Messaging Rules (Like WhatsApp Community)

### 🔔 Announcement Channel (Mentor-Only)

**Who Can Post**: Only mentors

**What Mentors Can Share**:
- ✅ Test announcements
- ✅ Important updates
- ✅ Deadlines
- ✅ Study materials
- ✅ Links & files

**What Students Can Do**:
- ✅ Read messages
- ✅ React with emojis (👍 ❤️ 🔥)
- ❌ Cannot reply
- ❌ Cannot send messages

**Use Cases**:
- Exam schedules
- Assignment deadlines
- Important notices
- Rule updates

---

### 💬 Discussion Channel (Controlled)

**Who Can Post**: Students + Mentors

**Student Permissions**:
- ✅ Send messages
- ✅ Ask questions
- ✅ Share resources
- ✅ Reply to others

**Mentor Moderation**:
- ✅ Delete inappropriate messages
- ✅ Mute specific students
- ✅ Lock discussion temporarily
- ✅ Pin important messages

**Auto-Moderation** (AI-powered):
- Flags spam
- Flags abuse
- Flags off-topic content
- **Mentor has final decision**

---

## 5️⃣ Test & Exam Rules Inside Community

### 📝 Test Scheduling
- Mentor can schedule:
  - **Individual tests** (one student)
  - **Group tests** (entire community)

### 🔒 During Live Test
**Automatic Restrictions**:
- 🚫 Community chat **locked**
- 🚫 Private messaging **disabled**
- 🚫 Cannot leave test tab
- 🚫 Cannot switch windows

**Monitoring Active**:
- ✅ Screen recording
- ✅ Face monitoring
- ✅ Tab switch detection
- ✅ Activity logging

**Violations Logged**:
- Tab switches
- Window changes
- Copy/paste attempts
- Suspicious behavior

---

## 6️⃣ Code of Conduct (Mandatory)

### ✅ Required Behavior
- Professional language only
- Respectful communication
- On-topic discussions
- Honest participation
- Help others learn

### ❌ Prohibited Behavior
- Abuse or harassment
- Spam or flooding
- Off-topic discussions
- Sharing test answers
- Fake identity
- Sharing test links outside
- Plagiarism
- Cheating

### ⚠️ Violation Levels

| Level | Action | Duration |
|-------|--------|----------|
| 1st Warning | ⚠️ Warning message | - |
| 2nd Warning | ⛔ Temporary mute | 24 hours |
| 3rd Warning | ⛔ Temporary mute | 7 days |
| Severe | 🚫 Permanent removal | Forever |

**Severe Violations** (Instant Removal):
- Cheating during tests
- Harassment
- Sharing confidential content
- Impersonation

---

## 7️⃣ Mentor Control Powers

### 👨‍🏫 Full Control
Mentor can:
- ✅ Edit community details
- ✅ Approve/remove members
- ✅ Mute individuals
- ✅ Mute entire community
- ✅ Lock community during exams
- ✅ Delete messages
- ✅ Pin important messages
- ✅ Assign group tasks
- ✅ Schedule group tests
- ✅ View all activity logs
- ✅ Export member list
- ✅ Archive community

### 🎯 Mentor Decisions
- Mentor decisions are **final**
- No appeals within platform
- Students can report to university admin (external)

---

## 8️⃣ Privacy & Security Rules

### 🔒 Privacy
- Community content is **private**
- Only members can see messages
- Search engines **cannot index**

### 📸 Recording & Monitoring
**During Normal Discussion**:
- ❌ No screen recording
- ❌ No face monitoring
- ✅ Message logs only

**During Live Tests**:
- ✅ Screen recording (with consent)
- ✅ Face monitoring (with consent)
- ✅ Activity logging
- ✅ Tab switch detection

**Student Consent**:
- Required before first test
- Can be revoked (but cannot take tests)

### 🗄️ Data Retention
- Messages: **Forever** (unless deleted)
- Test recordings: **90 days**
- Activity logs: **1 year**
- Removed members: **Anonymized after 30 days**

---

## 9️⃣ Activity & Inactivity Rules

### 📊 Activity Tracking
- Last message sent
- Last test taken
- Last login
- Participation rate

### ⏰ Inactivity Thresholds
| Duration | Action |
|----------|--------|
| 30 days | ⚠️ Flagged as inactive |
| 60 days | 🔔 Reminder notification |
| 90 days | ⛔ Auto-removed (configurable) |

### 🔄 Re-activation
- Removed students can **request to rejoin**
- Mentor must **re-approve**

---

## 🔟 Leaving & Removal Rules

### 🚪 Student Leaving
- Can leave **anytime**
- No questions asked
- Can **rejoin later** (needs approval)

### 🚫 Mentor Removal
- **Immediate** effect
- Student gets notification
- Cannot rejoin without **fresh approval**
- Removal reason **optional** (mentor's choice)

### 🗑️ Community Deletion
- **Only mentor** can delete
- All data **archived** (not visible to students)
- Members get **notification**
- Cannot be undone

---

## 1️⃣1️⃣ AI Moderation Rules

### 🤖 AI Capabilities
AI automatically flags:
- Spam messages
- Abusive language
- Off-topic content
- Repeated violations
- Suspicious test behavior

### 👨‍🏫 Mentor Authority
- AI **does not auto-ban**
- AI **only flags** for review
- Mentor **always has final decision**
- Mentor can **override AI**

---

## 1️⃣2️⃣ Community Purpose Rule

### 📋 Required Information
Every community must define:
- **Goal**: What is this community for?
- **Duration**: How long will it run? (optional)
- **Expected Behavior**: What's allowed/not allowed?
- **Meeting Schedule**: When are live sessions? (optional)

### 📝 Example Purpose Statement
```
Purpose: Interview Preparation for Frontend Roles
Duration: 3 months (Jan - Mar 2025)
Expected Behavior: 
- Only interview-related discussions
- No casual chat
- Participate in weekly mock interviews
- Complete assigned practice problems
Meeting Schedule: Every Saturday 10 AM
```

### ✨ Unique Features
